# ECORA 🌿

AI-powered sustainable shopping marketplace.

## Features
- Sustainable product marketplace
- Product categories and search
- Shopping wishlist
- Shopping bag
- AI shopping assistant
- Responsive design

## Installation

npm install

## Development

npm run dev

Visit http://localhost:3000

## Environment variables

Create .env.local:

OPENAI_API_KEY=your_key
OPENAI_MODEL=gpt-5.5

## Deployment

1. Upload the project to GitHub.
2. Import the repository into Vercel.
3. Add OPENAI_API_KEY to Vercel Environment Variables.
4. Deploy.

## Important

The included products are sample catalogue data.
Replace them with verified supplier products and sustainability
documentation before launching the marketplace.

The cart is a front-end demo and does not process payments.
